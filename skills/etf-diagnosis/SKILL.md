# ETF 持仓诊断与机会发现

基于东方财富数据，对 ETF/LOF 进行**多维度诊断**或**全市场机会扫描**，返回结构化 Markdown 报告。

## 功能范围

### 模式一：持仓诊断（指定代码）

输入 ETF 代码列表 → 自动拉取核心指标 → 横向对比 → 生成诊断报告

**诊断维度：**
- 收益表现（近1月/3月/1年回报）
- 风险调整（夏普比率、年化波动率、最大回撤）
- 折溢价风险（市价 vs 净值偏离）
- 资金流向（主力净流入/流出）
- 同赛道排名（自动匹配赛道，横向对比同类 ETF）
- 宏观背景（中美通胀、利率、地缘风险）

### 模式二：机会扫描（无需指定代码）

全市场扫描 → 多维打分 → 推送排名靠前的机会

**扫描维度：**
- 🟢 折价机会（市价 < 净值 >1.5%）
- 💰 资金异动（主力大幅流入）
- 🚀 动量延续（近1月涨幅最强）
- 📉 超跌反弹（短期急跌，可能反弹）
- 📊 放量异动（成交突增）
- ⚠️ 溢价风险（溢价 >5%，远离）

### 触发规则

**触发（诊断模式）：**
- "分析一下我的ETF持仓"
- "512480和513650怎么样"
- "帮我看看这几只ETF"
- "ETF调仓建议"
- "我的ETF组合需要调整吗"

**触发（扫描模式）：**
- "今天有什么ETF机会"
- "扫一下市场"
- "有什么值得关注的ETF"
- "ETF异动"
- "自选池有没有买卖机会"

### 不触发规则
- 个股诊断（走 stock-diagnosis）
- 场外基金诊断（走 fund-diagnosis）
- 精确技术指标计算（MACD、RSI等）
- 港股/美股单票分析

## 快速开始

### 持仓诊断

```bash
python3 {baseDir}/scripts/diagnose.py 512480 513650
```

输出：`etf_diagnosis_report.md`

### 机会扫描

```bash
python3 {baseDir}/scripts/scan.py
```

输出：`etf_opportunities.md`

### 参数说明

| 模式 | 命令 | 参数 |
|------|------|------|
| 诊断 | `diagnose.py <code1> <code2> ...` | ETF 代码，空格分隔 |
| 扫描 | `scan.py` | 无需参数 |

---

## 输出文件

| 模式 | 文件 | 说明 |
|------|------|------|
| 诊断 | `etf_diagnosis_report.md` | 核心指标对比 + 资金流向 + 同类排名 + 宏观背景 |
| 扫描 | `etf_opportunities.md` | 按维度分组的机会列表 + 综合得分排名 |

## Slash 命令

| 命令 | 功能 |
|------|------|
| `/portfolio show` | 查看当前持仓和现金 |
| `/portfolio add <代码> <名称> <份数> <成本价>` | 添加持仓 |
| `/portfolio remove <代码>` | 移除持仓 |
| `/portfolio cash <金额>` | 更新现金余额 |
| `/portfolio alert <代码> <类型> <阈值>` | 添加预警 |

## 自动化

- **SessionStart 钩子**：每次打开 ZCode 自动检查持仓和 API 状态
- **预警系统**：定时检查溢价/回撤是否触发阈值

## 实现说明

- 数据源：东方财富妙想 API
- 状态存储：`~/.zcode/portfolio.json`（跨会话持久化）
- 诊断流程：拉指标 → 拉排名 → 拉宏观 → 生成报告
- 扫描流程：6 维度并行筛选 → 去重 → 多因子评分 → 排序输出
- 交易所覆盖：上交所（SH）、深交所（SZ）
