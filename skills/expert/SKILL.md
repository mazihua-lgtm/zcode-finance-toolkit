# 🧠 ZCode 专家系统

理解你的意图，匹配最佳技能，编排工作流。

## 功能

- **智能路由**：你说需求 → 自动匹配最相关的技能
- **工作流编排**：复杂任务自动拆解为多步流程
- **规则 + AI 双引擎**：高频场景手工映射确保准确，长尾场景语义匹配兜底

## 使用

直接说出你的需求：

```
"帮我分析ETF持仓"       → etf-diagnosis + mx-finance-data
"今天复盘"             → 热点→行情→新闻 三步工作流
"写半导体深度报告"      → 信息收集→数据→深度分析→对比 四步
"压缩一下prompt"       → promptpress
```

## 内置工作流

| 工作流 | 步骤 |
|------|------|
| 投资研究 | 信息收集 → 数据查询 → 深度分析 → 同行对比 |
| 持仓管理 | 持仓诊断 → 机会扫描 → 调仓建议 |
| 每日复盘 | 热点扫描 → 行情数据 → 重要新闻 |
| 文档处理 | 内容撰写 → 格式转换 → 云端存储 |

## 命令行

```bash
python3 {baseDir}/scripts/expert.py "你的需求"
```
